## Ansible Task - Install Nginx on Pathnex Server

I  Rewrite the below code by typing in terminal from VS code terminal 

-------

- name: Install Nginx on Pathnex server
  hosts: all
  become: yes
 
  tasks: 
    - name: Install Nginx
      yum:
        name: nginx
        state: present

## Kubernetes Task - Create Nginx Pod

  apiVersion: v1
  kind: Pod
  metadata:
      name: pathnex-pod
  spec:
     containers:
      - name: web
        image: nginx:latest
        ports:
          - containerPort: 80
